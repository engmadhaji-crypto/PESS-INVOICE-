# PESS V36 Android APK

هذا مشروع تغليف Android أصلي لواجهة PESS V36 باستخدام Android WebView، ويُبنى تلقائياً عبر GitHub Actions دون الحاجة إلى Android Studio على جهاز المستخدم.

## بناء APK
1. ارفع مجلد `android-app` وملف `.github/workflows/build-pess-v36-apk.yml` إلى جذر المستودع (مع الحفاظ على المسارات).
2. افتح تبويب Actions.
3. اختر Build PESS V36 APK ثم Run workflow.
4. بعد نجاح البناء افتح نتيجة التشغيل وحمّل artifact باسم `PESS-V36-debug-apk`.
5. فك ZIP الناتج وثبّت APK على هاتف Android.

## ملاحظات مهمة
- يستخدم التطبيق WebViewAssetLoader لأصل HTTPS محلي ثابت، مع تفعيل DOM Storage وIndexedDB وحفظ WebView.
- ملفات النسخ الاحتياطية التي تنشئها الواجهة عبر Blob تُحفظ إلى Downloads/PESS، كما تُمرّر التنزيلات المباشرة عبر DownloadManager.
- الطباعة تُفتح عبر خدمة الطباعة في Android.
- موارد واجهة React/Babel/Tailwind الخارجية ما زالت تُحمّل من CDN؛ لذلك يتطلب التشغيل الأول اتصال إنترنت. لا تعتبر هذه النسخة Offline بالكامل.
- لم يتم اختبار هذا البناء على هاتف حقيقي بعد. اختبر أولاً الحفظ، إغلاق التطبيق وإعادة فتحه، تنزيل نسخة JSON واستعادتها قبل اعتمادها للبيانات الفعلية.
- هذا APK تجريبي Debug وغير موقّع بمفتاح إصدار دائم. لا تحذف هذه النسخة لتحديثها لاحقاً؛ يلزم تجهيز توقيع Release ثابت قبل التوزيع النهائي.
